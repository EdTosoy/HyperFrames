# Human voice-over recordings

Use `recordings/<episode-id>/take-01.wav`, `take-02.wav`, and immutable correction
takes. Keep a separate `edit-v01.wav` for the approved trimmed/normalized cut.
Audio is ignored; small text notes, transcripts and edit logs can be tracked.
Declare required master and edit assets in the episode specification. Back up
masters in two independent locations before editing. See
[production workflow](../docs/PRODUCTION_WORKFLOW.md).
