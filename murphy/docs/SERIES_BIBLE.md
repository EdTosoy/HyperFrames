# Series bible — English, Made Clear.

Audience: beginning English learners, usually A1–A2. Each episode teaches one
observable skill with one clear takeaway. A textbook unit may become several
short episodes. Branding is provisional and configured in production.json.

The curriculum reference is Raymond Murphy's _Essential Grammar in Use_, red book.
Unit/part metadata organizes original teaching, not reproduction of the book.
This project is not affiliated with its author or publisher.

Use this sequence: hook → real-life example → visual explanation → grammar
breakdown → guided practice → recap. Vary examples, contexts, visuals and scene
lengths to serve the objective. A phase can contain several scenes; keep the order
intelligible. Prefer 45–90 seconds; explain exceptions in `durationReason`. Avoid
compressing learning to hit an arbitrary duration.

Voice: warm, precise, direct English, recorded by the owner. Use restrained motion
to show a grammatical relationship. Give learners time to read, think and respond
before quiz answers appear. Repeat visual anchors while varying illustrations or
practice types.

Explanations, examples, exercises, diagrams and illustrations must be original.
Follow [teaching standards](TEACHING_STANDARDS.md), [visual system](VISUAL_SYSTEM.md)
and [asset policy](ASSET_POLICY.md). The existing lesson is a historical sample;
the factory fixture is an infrastructure test and can never be published.
