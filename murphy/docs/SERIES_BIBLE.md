# Series bible — English, Made Clear.

Audience: beginning English learners, usually A1–A2. Each video covers one complete
textbook unit with a clear learning objective, explanation, examples, practice and
recap. Owner direction (2026-11-06): the curriculum has 115 units, targeting 115
lesson videos. Do not split a unit into separately released part videos; organize
its subtopics as sections inside the same video. Branding is provisional and
configured in production.json.

The curriculum reference is Raymond Murphy's _Essential Grammar in Use_, red book.
Unit metadata organizes original teaching, not reproduction of the book. The
existing schema's part field is an internal compatibility detail, not a requirement
to create multiple videos or show part labels to learners.
This project is not affiliated with its author or publisher.

Use this sequence: hook → real-life example → visual explanation → grammar
breakdown → guided practice → recap. Vary examples, contexts, visuals and scene
lengths to serve the objective. A phase can contain several scenes; keep the order
intelligible. Set duration from the complete unit's teaching needs and reading/
practice time. The former 45–90-second preference must not force a unit into
multiple videos; explain longer durations in `durationReason`. Avoid compressing
learning to hit an arbitrary duration.

Voice: warm, precise, direct English, recorded by the owner. Use restrained motion
to show a grammatical relationship. Give learners time to read, think and respond
before quiz answers appear. Repeat visual anchors while varying illustrations or
practice types.

Teaching explanations, examples and exercises must be independently written.
Use suitable licensed provider visuals before custom illustrations; custom
diagrams and artwork must be original. Never copy textbook visuals or layouts.
Follow [teaching standards](TEACHING_STANDARDS.md), [visual system](VISUAL_SYSTEM.md)
and [asset policy](ASSET_POLICY.md). The existing lesson is a historical sample;
the factory fixture is an infrastructure test and can never be published.
